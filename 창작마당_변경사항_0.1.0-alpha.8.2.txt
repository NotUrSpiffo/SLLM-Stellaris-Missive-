🔧 SLLM 알파 8.1 · 8.2 핫픽스

알파 8을 쓰고 계신 분을 위한 작은 수정입니다. 창작마당 모드를 구독한 채로 두면 앱이 「새 버전을 설치할 수 있습니다」라고 물어보고, 업데이트를 누르면 끝입니다. 대화 기록과 설정은 그대로입니다.

🩹 알파 8.1 (긴급)
• 내각 회의: 회의실 배경만 나오고 장관·의제·단추가 비어 있던 문제.
• 외교 서신: 편지를 열어도 본문이 안 보이던 문제. 창이 낮으면 편지를 열 때 위쪽 제목·버튼·목록이 접히고, 「◂ 편지 목록」으로 돌아갑니다.
• 신문 호외: 기사에 NAME_… 같은 게임 내부 이름이 그대로 나오던 문제. 해적·사라진 내부 세력의 멸망은 더 이상 보도되지 않습니다. 이미 나온 호외는 그대로 남습니다.

🔧 알파 8.2
• Google Agent Platform(Vertex AI): 「API 키는 지원되지 않습니다」(401) 오류로 연결되지 않던 문제. 서비스 계정 JSON 파일의 내용 전체를 API 키 칸에 붙여 넣으면 연결됩니다. 서비스 계정에는 「Vertex AI 사용자」 역할이 필요하고, 위치를 바꾸려면 API 주소를 고치면 됩니다.

📌 확인 상태
타입 검사와 자동 검사를 통과했습니다. Google 서비스 계정 연결은 실제 Google 계정으로는 아직 확인 전입니다.
