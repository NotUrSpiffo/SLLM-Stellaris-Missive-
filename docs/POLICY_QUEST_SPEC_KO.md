# 정책 퀘스트 설계서 (알파 7 예정, 2026-10-18 초안 → 사용자 확인 대기)

집무실에 「정책」 칸을 만든다. 플레이어가 제목·내용을 자유롭게 쓴 칙령·정책을 선포하면, 정해진 버프가 걸리고, 그 대신 **무작위로 붙은 유지 조건**을 모드가 매달 판정한다. 조건을 지키는 동안만 버프가 유지된다.
사용자 확정 사항(12:21~12:23)은 ★ 표시. 나머지는 이 문서의 제안이며 확인 뒤 구현한다.

## 1. 한눈에

| 항목 | 내용 |
| --- | --- |
| 정책 종류 ★ | 내부 정책 / 외부 정책. 동시에 내부 1 + 외부 1 까지 |
| 선언문 ★ | 제목(40자)·본문(600자)은 플레이어가 자유롭게 씀(롤플레이). AI 가 고치지 않음 |
| 목표 ★ | 정책마다 2개. 목표 = 버프 1 + 유지 조건 1 |
| 버프 ★ | 버프 목록(buff-catalog 99종)에서 고름. 내부 = 경제·연구·사회·건설·제국 운영·지도자·탐사 / 외부 = 외교·첩보·함대·지상군 + 교역 가치 |
| 난이도 ★ | 목표마다 플레이어가 쉬움/보통/어려움 선택 → 버프 +5/+10/+20%(기존 1·2·3단계, 숫자형 버프는 목록의 단계값) |
| 조건 ★ | 난이도와 같은 폭(+5/+10/+20%)으로 시행 때 값보다 높게 유지. 그 난이도 안에서 무작위, 목표마다 다시 뽑기 1회 |
| 기간 | 플레이어가 1·2·3년 중 선택(기본 2년, 사용자 확정 10-18: 최대 3년). 예전 세이브 정책은 2년 |
| 판정 | 모드가 매달(on_monthly_pulse_country). 수입 조건은 첫 6개월 달성 기간 뒤부터 |
| 어기면 | 2개월 유예(경고 알림·신문 한 줄) → 그래도 못 맞추면 그 목표만 실패: 버프 꺼짐 + 불이익 1년 |
| 둘 다 실패·중도 폐지 | 정책 붕괴: 불이익 + 같은 종류 정책 1년 금지 |
| 기간 완주 | 성공: 기사 + 「정책 유산」(두 버프를 1단계로 1년 더) 또는 연장(조건 다시 뽑기, 1~3년 다시 선택) |
| AI 호출 | 정책당 최대 2번(버프 추천 1, 외부 정책 반응 서신 1). 판정·기사·경고는 AI 없음 |

## 2. 유지 조건 목록

시행 순간 모드가 기준값(base)을 재서 변수에 저장하고, 목표값 = base × (1 + 단계%) 또는 base + 단계값. 매달 현재값을 재서 비교한다.

### 내부 조건 (우리 제국만)
| 조건 | 쉬움 (+5%) | 보통 (+10%) | 어려움 (+20%) | 모드 판정 방법 | 확인 상태 |
| --- | --- | --- | --- | --- | --- |
| 자원 월 수입 유지 (에너지·광물·식량·합금·소비재·통합·물리·사회·공학 중 1) | base×1.05 | ×1.10 | ×1.20 | `export_trigger_value_to_variable { trigger = has_monthly_income parameters = { resource = X } }` | **게임 확인 1순위**(안 되면 창고 조건으로 대체) |
| 창고 보유량 유지 (에너지·광물·식량·합금·소비재 중 1) | base×1.05 | ×1.10 | ×1.20 | `has_resource = { type = X amount >= 목표 }` (만찬 선물에서 이미 씀) | 확실 |
| 수도 안정도 | base+5 | +10 | +20 | `capital_scope = { planet_stability >= 목표 }` | 거의 확실 |
| 행성 수 유지 | 줄지 않기 | +1 | +2 | `num_owned_planets` | 확실 |
| 해군 사용률 | 60% 이상 | 75% | 90% | `used_naval_capacity_percent` | 게임 확인 |
| 전쟁 중 아님 | 쉬움만 | – | – | `is_at_war = no` | 확실 |

- 수입·창고 조건은 "첫 6개월은 달성 기간"(판정 안 함), 7개월째부터 매달 판정.
- 기준값이 0 이거나 너무 작으면(수입 10 미만) 그 조건은 뽑히지 않는다.

### 외부 조건 (다른 제국이 걸림)
외부 정책은 만들 때 **대상 제국**을 하나 고른다(연락처에 있는 제국 중). 조건은 대부분 그 제국을 기준으로 붙는다.

| 조건 | 쉬움 | 보통 | 어려움 | 판정 | 확인 상태 |
| --- | --- | --- | --- | --- | --- |
| 대상 제국과 우호 | 관계 ≥ base+25 | +50 | +100 | `opinion = { who = 대상 value >= 목표 }`(첩보에서 이미 씀) | 확실 |
| 대상 제국과 적대 (배척·강경 정책) | 관계 ≤ base−25 | −50 | −100 | 같음 | 확실 |
| 대상 제국과 전쟁 중 아님 / 먼저 전쟁 걸지 않음 | 쉬움만 | – | – | `is_at_war_with = 대상` + 모드가 on_war_started 로 공격 기록 | 공격 판별은 게임 확인 |
| 연방 회원 유지 | 쉬움만 | – | – | `is_in_federation = yes` (연방이 있을 때만 뽑힘) | 확실 |
| 은하 공동체 회원 유지 | 쉬움만 | – | – | `is_galactic_community_member = yes` | 확실 |
| 모든 종속국 충성도 | ≥ base−10 | ≥ base | ≥ base+10 | `every_subject` + `has_loyalty`(종속국 채널에서 이미 씀) | 확실 |
| 연구·통상 협약 1개 이상 유지 | 쉬움만 | – | – | `has_research_agreement`/`has_commercial_pact` | 게임 확인 |

- 예/아니오 조건은 쉬움에만 있으므로 보통·어려움을 고르면 숫자 조건만 뽑힌다.
- 대상 제국이 사라지면(멸망·흡수) 그 목표는 자동 성공 처리(플레이어 잘못이 아님).

## 3. 진행 흐름

```
[작성] 종류 고르기 → (외부면 대상 제국) → 제목·본문 → 버프 2개 고르기(AI 추천 3개 참고) → 목표마다 난이도 → 조건 뽑힘(각 1회 다시 뽑기) → 확인 카드
   ↓ 선포(게임에 적용: 기준값 측정 + 버프 2개 add_modifier 720일)
[시행 중] 매달 판정 → 목표마다 상태: 달성 기간 / 유지 중 / 경고(1·2개월째) / 실패 / 성공
   ↓
[끝] 기간(1~3년) 완주 = 성공  |  목표 하나 실패 = 그 버프만 끄고 불이익  |  둘 다 실패 또는 폐지 = 붕괴
```

- 경고: 어긴 달 1·2 → 알림 카드 + 집무실 정책 카드 빨간 표시 + 신문 자료 한 줄("○○ 정책, 목표 미달 N개월째"). 3개월째 판정에도 미달이면 실패.
- 실패 불이익(1년): 내부 = 모든 행성 안정도 −5(`sllm_policy_broken_in`), 외부 = 대상 제국의 우리 관계 −50(매달 4 회복, `sllm_policy_broken_ex`).
- 붕괴: 위 불이익 + 같은 종류(내부/외부) 정책 360일 선포 금지("국민 신뢰 회복 중").
- 성공 보상: 「정책 유산」 = 두 버프를 1단계(+5%)로 360일 더(`add_modifier` 다시). 또는 연장: 같은 버프·같은 난이도로 조건만 다시 뽑고 1~3년 더(연장 중엔 유산 없음, 완주 때 지급).
- 폐지 버튼은 확인 두 번(붕괴 불이익 안내).

## 4. 롤플레이 연결 (AI 호출 최소)

| 곳 | 무엇 | AI |
| --- | --- | --- |
| 신문·라디오 | 월간 자료에 정책 줄: 선포·경고·실패·성공(제목 + 한 줄 요약). 기존 월간 생성에 얹히므로 추가 호출 없음 | 0 |
| 연대기 | 선포/실패/성공 한 줄 | 0 |
| 버프 추천 | 제목·본문·제국 성향 → 허용 목록 안에서 버프 3개 + 한 줄 이유. 플레이어는 무시해도 됨 | 1 |
| 외부 정책 반응 | 선포 때 대상 제국이 서신 1통(기존 서신 기능, 종류 '정책 반응': 우호 정책이면 환영, 적대면 항의). 관계 수치는 조건·불이익으로만 바뀜 | 1 |
| 내부 정책 반응 | 파벌 회의 프롬프트에 "시행 중인 정책" 줄 → 다음 회의에서 파벌이 언급. 총독 대화·인물 통신 프롬프트에도 한 줄 | 0 |
| 언론사 인터뷰 | 인터뷰 열려 있으면 '정부 발표' 주제로 정책을 발표할 수 있음(선택). 평가 좋으면 그 정책의 내부 불이익을 다음 1회 면제 | 기존 호출 안에서 |

## 5. 화면 (집무실 안, 별도 창 없음)

- 바탕화면 「국정」 묶음에 **정책** 아이콘(두루마리/인장). 시행 중 정책에 경고가 있으면 숫자 배지.
- **정책 화면**: 위에 내부/외부 슬롯 카드 2장. 카드 = 제목·종류·남은 개월·목표 2개 게이지(현재값/목표값, 상태 색: 달성 기간 회색·유지 초록·경고 노랑·실패 빨강·성공 금색)·폐지 버튼. 빈 슬롯은 「새 정책」, 금지 중이면 남은 기간.
- **새 정책 마법사**(4단계, 뒤로 가기 가능): ① 종류(+외부면 대상 제국) ② 선언문 작성(공문서 모양 미리보기) ③ 버프 2개(목록 + AI 추천 3개 칩) ④ 목표마다 난이도 → 조건 카드(다시 뽑기 1회) → 선포 확인(효과·조건·불이익 요약).
- **정책 문서 보기**: 선포된 선언문을 공문서(인장·날짜·서명) 모양으로. 종속국 공문과 같은 종이 어법.
- **지난 정책**: 성공/실패/붕괴 기록 목록.
- 한/영 카탈로그 + 언어 팩 규칙 준수(L/pick·카탈로그만, 'en' 직접 판정 금지).

## 6. 모드·앱 구조

### 모드(tester-mod, 연결 규격 5 유지 — 구버전 모드면 정책 화면에 "모드 업데이트 필요" 안내)
- `common/scripted_effects/sllm_probe_policy.txt`
  - `sllm_policy_enact = { SLOT N KEY1 KEY2 COND1 … }`: 기준값 측정(export) → 변수 `sllm_pol_<slot>_base1/2·target1/2·cond1/2·start`, 버프 2개 `add_modifier days=720`, 플래그 `sllm_pol_<slot>_on`. 로그 `SLLM:POLICY/;/phase=enacted/;/slot/;/base1/;/base2/;/status=applied|failed`.
  - `sllm_policy_goal_off = { SLOT G }`: 그 버프 제거 + 불이익 수정자. `sllm_policy_end = { SLOT OUTCOME }`: 전부 제거·변수 정리·성공이면 유산 수정자.
- `events/sllm_policy_events.txt` + `on_actions`: 매달(플레이어만, 플래그 있을 때) 목표마다 현재값 측정 → `SLLM:POLICY/;/phase=tick/;/slot/;/g/;/cur/;/target/;/ok`. 판정(유예·실패)은 앱이 하고 명령을 보냄(다른 기능과 같은 방식, selftest 로 시험 가능). on_war_started 로 공격 전쟁 표시.
- `static_modifiers/sllm_policy_modifiers.txt`: `sllm_policy_broken_in`(planet_stability −5), `sllm_policy_legacy_*` 는 기존 buff t1 재사용. `opinion_modifiers/sllm_policy_opinion.txt`: `sllm_policy_broken_ex`(−50, decay 4).
- 한/영 localisation.

### 앱
- `src/policy.ts`(순수): 조건 목록·뽑기(난이도·종류·제국 상황 필터)·목표값 계산·월간 판정 상태기계(달성 기간/유지/경고 n/실패/성공)·명령 문자열·신문 자료 줄·AI 추천 프롬프트/파싱.
- `src/features/policy-app.ts`: 세이브별 `sllm_policy.json`, 로그 자리 POLICY 262, IPC `policyState·policyRecommend·policyEnact·policyReroll·policyRepeal·policyExtend`, 알림 카드, 월간 자료 훅(media·radio·chronicle·faction·persona).
- `ui/office.html` 정책 화면 + CSS, 카탈로그 영어, selftest 블록(조건 뽑기 범위·목표값·상태기계·명령 문자열·언어 팩 규칙).

## 7. 게임에서 꼭 확인할 것 (구현 뒤)
1. `has_monthly_income` 값 export 가 되는지(안 되면 수입 조건 → 창고 조건으로 대체).
2. `used_naval_capacity_percent`, `has_research_agreement/has_commercial_pact`, on_war_started 의 공격 측 판별.
3. 720일 수정자 + 중간 제거/재적용이 꼬이지 않는지(연설 버프와 키가 겹치지 않게 `sllm_buff_*` 재사용 시 연설과 같은 버프를 고르면 둘 중 하나만 남는 문제 → **정책은 연설이 쓰는 버프와 겹쳐도 되게, 연설 효과 적용 시 remove 목록에 정책 키가 없음을 확인**).
4. 세이브 바꿈·재로드 때 정책 상태가 그 세이브 것만 보이는지(다른 기능과 같은 sid 가드).

## 8. 만드는 순서(예상 한 세션)
1. policy.ts 순수 로직 + selftest → 2. 모드 효과·이벤트·수정자·문구 → 3. policy-app IPC·월간 훅 → 4. 집무실 화면(마법사·카드·문서) → 5. 신문·라디오·연대기·파벌·서신 연결 → 6. 한/영·언어 팩 검사, 헤드리스 화면 확인 → 7. 네 곳 모드 반영·작업 기록.
집무실(office.html)을 고치는 다른 세션 작업이 끝난 뒤 시작한다(같은 파일 충돌 방지).
