- 추가팀: (A-17은 1단계로 당김, **A-01 화면 시연은 A-00b 직후로 당김**) A-07·A-18(A-00b 6단계 직후)(일시정지·교신 거절·몰락 제국 — 이제 막힌 것 없음) → A-04(초상화) → A-11(반란 출신) → **A-01(연방 회의)** → A-06(내정, 막힌 것 없음) → A-10(플래그 + 가중치, 연방 정상회담 전용, E-20~23 결과에 따라) → A-05(평화 중재) → A-03·A-08(첩보 읽기 가능해져 실현성 올라감)·A-02(보류)
- 바뀐 점: 연방 회의와 내정이 문서로 풀려서 A-10보다 앞으로 옴. 연방 회의의 군사 방침 부분만 A-10을 기다림

**팀 공통 규칙**
- 작업 전에 사용자의 최신 소스를 기준으로 삼는다. 결과는 바뀐 파일 목록 + 변경 요약으로 돌려주고, 사용자가 합친다
- 같은 단계에서 두 팀이 같은 파일을 고치지 않는다. 겹치면 총괄에 먼저 알린다 (1단계: `selftest.ts`는 추가팀·수정팀이 시점을 맞춤)
- 줄바꿈(CRLF/LF)은 원래대로 유지하고, 저장 뒤 원본과 달라진 줄이 변경분뿐인지 확인한다
- 탐색 결론의 근거가 4.5.1 문서면 "문서 기준(4.5.1)"으로 표시한다. 4.5.2 문서를 받으면 바뀐 이름이 있는지 한 번 대조한다
- 끝낸 항목은 자기 팀 문서에 `[x]` + 날짜 + 결론 + 근거로 남긴다. 총괄이 모아 이 문서를 갱신한다
