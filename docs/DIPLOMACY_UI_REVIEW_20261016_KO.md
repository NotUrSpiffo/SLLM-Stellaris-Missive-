## UI 오류와 수정

1. 의회 의원석 소실: 이전 툴팁 수정 중 layout 내부 seatsOf까지 seatCount로 잘못 치환되어 그리기가 중단되었다. 당시 오류는 council.html:280 seatCount is not defined. hover 인자는 seatCount, layout은 seatsOf[mi]를 사용하도록 바로잡았다. 실제 Electron에서 회원 13개 데이터로 의원석 84개 생성·hover·반복 layout을 검사했고 오류가 없었다.
2. 신문 여백: 창은 최대 1700px, 지면은 1320px으로 제한되어 양옆에 빈 면적이 생겼다. 창 너비를 최대 1320px(작은 화면은 가용 너비)로 고정하고 가로 최대화를 막았다. 실제 렌더러에서 지면 왼쪽 0px, 창 1304px/지면 1293px(차이는 세로 스크롤바) 확인.
3. 첩보 발언 잘림: 보존된 응답 자체가 문장 중간에 끝난 사례가 있다. maxTokens=700 요청이 696 completionTokens, finishReason=stop, outputChars=195로 보고되어 finishReason만으로 잘림을 확정할 수 없다. 응답 여유를 1400으로 늘리고 2~3문단 내 문장 완결 지시를 추가했다. 재판석 아래 긴 텍스트 중첩을 제거하고 대화 로그에서 전체 발언을 표시한다. 새 실제 AI 응답의 완결 여부는 추가 확인 필요.
4. 첩보 채팅: 발언자별 메시지 카드, 플레이어 오른쪽 정렬, 판사 판정 구분, 대화 스크롤·입력 영역 분리, 테마 스크롤바를 적용했다. 실제 렌더러에서 입력 영역이 창 내부에 있는지 확인했다.

## 변경된 첩보 규칙

- 각 증거에 대해 상대 제국과 3회 공방. 1·2회에는 판사 호출이나 조기 판정을 하지 않는다.
- 3회차 상대 답변 후 별도 재판소 AI가 누적 공방을 요약하고 해당 증거의 승리자를 발표한다. 세 증거를 순차 진행한다.
- ‘닫기’를 ‘퇴장하기’로 변경. 미완료 상태에서 버튼/창 닫기로 퇴장하면 실패 3건으로 종료한다. 산출량 -27%, 앱 호감도 -30, 게임 관계 -300, 720일의 최대 계산값. 이미 완료된 결과는 퇴장해도 바꾸지 않는다.
- 현재 첩보 기능은 개발자 가상 사건이며 gameApplied=false다. 실제 게임 수정자는 아직 연결되지 않았다. 화면에도 시험 수치·게임 미적용 안내를 유지했다.
