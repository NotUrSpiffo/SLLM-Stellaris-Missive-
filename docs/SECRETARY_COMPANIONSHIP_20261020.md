# 비서 후속 안부·조언 회상·조용한 동행

- 기념품 제외. 통치자별 Bond.followups에 최대 8건. 대화 종료 요약의 걱정/조언 인용을 실제 발화자 원문과 대조하여 저장. 기존 기록 소급 추측 없음.
- 후속 안부/조언: 같은 보고 항목의 관측 내용이 바뀌거나 사용자가 관련 주제를 다시 꺼낼 때 한 건만 프롬프트에 포함. 각 건은 한 번 제안. 보고 목록에서 사라진 것만으로 해결 판단하지 않음. 결과 모르면 질문, 조언을 따랐거나 원인이 되었다고 단정 금지.
- 조용히 있기: 일반 집무실 비서 대화에서 「그냥 곁에 있어 줘」, 정적인 대사·기본 표정, 입력창 숨김, 「다시 이야기하기」로 기존 대화 복귀. 진입/유지/복귀 추가 AI 호출·호감 변화·게임 효과 없음. 장면 퇴장은 기존 대화 요약 절차 유지.
- 기존 통치자 ID/세이브 경계 유지. 승계 후 과거 세션 사용 차단. 한/영 문구는 L/pick 사용.
- 실행 앱과 payload 적용, TypeScript 빌드 성공. 원문/발화자 확인·변화/관련성 선별·반복 억제·조용한 모드 무호출·통치자 차단 검사 및 한/영 UI 전환 검사 통과.
- 전체 검사에서 기존 환경 4건, agents/embassy 순환 참조, 다른 모듈 언어 팩 실패는 별도 담당 영역으로 남김. 실제 AI 답변/게임 장면 미검수. 모드·설치기 변경 없음.
