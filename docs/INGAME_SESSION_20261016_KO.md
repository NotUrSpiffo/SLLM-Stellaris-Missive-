## 3. 평의회 의제 — '무한한 기회' 종료 → '국력 배양' 채택 (중점)

용어: 사용자가 말한 '결의안'은 은하 공동체 결의안이 아니라 **제국 평의회 의제(council agenda)**다. 게임 데이터 위치는 `common/council_agendas/`(SLLM 문서의 `common/agendas` 는 틀린 경로).

### 3-1. 무한한 기회 (`agenda_infinite_opportunities`)

- 진행 중 효과: 시민 행복 +4%.
- 완료 효과(`agenda_infinite_opportunities_finish`): 시민 행복 **+10%**, 기본 3,600일(**10년**) 지속.

### 3-2. 국력 배양 (`agenda_strong_on_our_own`) — 새로 고른 의제
