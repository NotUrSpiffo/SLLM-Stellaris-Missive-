# F-41 과거 게임 로그 재생 수정

2026-10-16. 알파3 소스에 반영, 설치 EXE 재빌드는 아직 수행하지 않음.

## 변경

- 시작 시 존재하던 파일 바이트 범위를 과거 기록으로 표시. 과거 메시지는 요청 번호의 req/last 최대값 복구만 수행.
- 이후 이어 쓴 메시지만 기존 기능 분배기로 전달. 연설·월 신호·LOADED·신문·라디오·총독 요청 등 과거 기능 신호는 재실행되지 않음.
- 경계에 걸친 미완성 줄은 완성되어도 과거로 유지. 대용량 로그를 읽는 도중 추가된 줄은 실시간으로 유지.
- 감시 경로 변경/재시작에는 새 경계를 잡고, 로그 축소/다른 파일로 교체에는 새 실시간 로그로 전환. 초기화 시 sessionReady/lastModLineAt도 비움.
- historyEnd/replaying 상태와 watcher.history_complete 진단 추가.

## 검증

TypeScript 빌드 성공. 원본 전체 검사 PASS 701 / FAIL 0, 수정본 PASS 716 / FAIL 0. 추가 회귀 검사 15개는 실제 임시 파일과 SpeechStore/GovMemoryStore를 사용한다. 사용자 세이브/기억/키 파일은 사용하지 않았다.

과거 연설·월·불러오기 신호가 저장 파일을 바꾸지 않음, 새 월 신호에서 연설 준비 완료, 실제 되감기에서 총독 시간선 분기, 감시 재시작 시 중복 없음, UTF-8 중간 경계, 2MB 초과 로그, 재생 도중 이어쓰기, 파일 초기화·동일 크기 교체·새 생성·경로 변경 및 앱 이벤트 연결을 확인했다.
