# 제국 평의회 의제·파벌회의 변경 — 2026-10-16

사용자 결정: 파벌회의는 제국 평의회 의제를 논의하는 기능이다. 정치 파벌이 최소 2개 이상일 때만 실제 회의와 알림을 허용한다. 개발자 시연은 별도로 유지한다.

변경:
- 최신 앱의 자동 알림과 실제 회의 열기 진입점에 2개 이상 조건 적용.
- Stellaris 4.5.2 원본 `common/on_actions/00_on_actions.txt`의 `on_agenda_finished`(THIS=country)를 사용. 이는 의제 발동 순간이며, 진행도만 가득 찬 준비 완료 시점과 구분한다.
- 숨김 이벤트 `sllm_council_agenda.1`이 완료 신호와 새 파벌 상태를 즉시 출력한다. 월간 수집은 보조 경로로 유지한다.
- 앱은 같은 세이브·같은 날짜의 새 상태에만 완료 신호를 연결한다. 중복 알림을 막고 완료 사실을 연대기에 남긴다.
- 플레이어가 새 의제를 직접 선택한 것이 다음 상태에서 확인되면 기존처럼 미적용 회의를 취소한다. 파벌 수가 조건 미달이면 참석 대기도 해제한다.

검증: TypeScript 전체 타입 검사와 앱 빌드 통과. 격리 동작 검사에서 파벌 0/1개 차단·2개 허용, 월간 중복 억제, 완료 즉시 알림, 새 의제 선택 취소, 게슈탈트 제외, 완료 중복 및 다른 세이브/날짜 거부 통과.

적용: 실행 앱 소스·dist, 개발 이동 사본 소스·dist, 세 곳의 모드(앱 포함본, 독립 tester-mod, Documents 실제 등록본). 통합 설치 EXE는 재빌드하지 않았다.

실게임 검증은 아직 남아 있다. 현재 플레이는 파벌 0개로 수집되므로 알림이 뜨지 않는 것이 새 조건에 맞다. 새 on_action 파일을 읽으려면 게임을 재시작하고, 앱도 재시작해야 한다. 기존 진행 중인 게임에 과거 완료 신호를 재실행하지 않는다.

주의: 세이브에서 수동 조사로 확인 가능한 행동의 범위와 앱이 실시간으로 수집하는 범위는 다르다. 이번 변경은 제국 평의회 의제 완료 감지이며 전체 행동 감지를 구현한 것은 아니다.
