# 내정·파벌 회의실 재구성 — 2026-10-16

- 통치자석과 파벌 대표들이 긴 회의 테이블을 둘러앉는 회의실. 초상화, 명패, 가치관·지지율, 각 대표의 표결 표시를 한 자리에 배치.
- 파벌 수 상한을 UI에서 새로 두지 않음. 파벌 수에 따라 테이블 폭 확장, 회의장 내부 가로 스크롤. 142px 명패·86px 초상화 크기 유지.
- 통치자석 위치는 테이블 왼쪽 끝. 파벌 ID 순서로 위·아래에 배치하여 지지율 변동만으로 자리가 바뀌지 않음. 추가·삭제 시 재배치.
- 의석 클릭/Enter/Space로 개별 발언 대상 선택. 선택한 파벌이 제거되면 전체 대상으로 복귀. 발언자 자리로 가로 화면 자동 이동.
- 기존 의제·보상·표결·강제 통과·AI·게임 적용 로직 유지. 화면 두 파일만 변경.
- 실제 Electron에서 파벌 0·1·3·8·16·30개로 좌석 수, 대표 이미지, 겹침 없음 확인. 30개 상태에서 파벌 ID 129 선택 및 제거 후 대상 초기화 확인. 900px 창의 16개 파벌 가로 스크롤·페이지 가로 넘침 없음 확인.
- 예시 이미지: 새 폴더/내정회의_새회의실_예시.png (가상 8파벌).
- 실제 게임·실제 API는 호출하지 않음. 새 설치 EXE/ZIP은 만들지 않음. 기존 전달 ZIP은 이전 스냅샷.
