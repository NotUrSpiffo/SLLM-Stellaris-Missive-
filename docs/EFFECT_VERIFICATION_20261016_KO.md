## 무엇을 검증하는가

효과마다 별도 요청 번호를 발급한다. 같은 세이브에서 기존 수정자 존재 여부를 확인하고, 기존 효과가 없을 때만 2일짜리 시험 효과를 추가한다. 게임의 has_modifier/has_opinion_modifier로 부착 여부를 확인한 뒤 즉시 제거하고 다시 존재 여부를 확인한다. 관계는 전후와 제거 후 원복 값을 추가로 기록한다. 효과별 요청 ID/효과 ID/세이브 ID가 맞아야 결과를 채택한다.

부착·제거가 확인됐다는 것이 생산량 보너스·파벌 승인도·지속 기간까지 검증됐다는 뜻은 아니다. 수치·기간·실제 기능 이벤트 연결은 별도 실게임 검수가 남는다. 첩보 시험은 에너지·광물·식량·합금·소비재 생산 제재를 사용하며, 모든 종류의 자원 산출량을 포괄한다고 주장하지 않는다.

기존 효과는 건너뛰며 제거하지 않는다. 제거 실패/응답 불명/세이브 변경이면 다음 항목을 중단하고 자동 재전송하지 않는다. 창을 닫거나 다음 검사 중단을 눌러도 이미 전송 중인 항목은 부착·제거를 끝낸 뒤 중단한다. 시험 도중 월간 갱신을 진행하면 일시적 효과가 생산량에 반영될 수 있으므로 일시정지 상태에서 사용한다.

선전포고, 종전, 연방 추방, 법률 변경, 의제 선택, 자원 거래 등 별도 상태 변경은 이 일괄 수정자 검사에 포함하지 않았다.

## 결과 보존

앱 데이터 `SLLM-Missive-Tester/effect-verification/<실행시간>.json`에 항목별 결과를 자동 저장한다. 같은 이름의 `.error.log`에는 실행 중 추가된 게임 오류 로그를 보존한다. 화면의 기록 폴더 버튼으로 결과 파일 위치를 연다.
