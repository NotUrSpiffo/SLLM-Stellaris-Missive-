# 평화 중재 기반 — 2026-10-16

이번 단계는 두 가상 AI 제국의 초청 → 백지평화 협상 → 합의/초청 거절 → 로컬 기록을 구현한다. 실제 전쟁 목록과 종전 효과는 연결하지 않았다.

## 사용

앱 재시작 후 설정 → 개발자 모드에서:

- **평화 중재 시험 (AI 없이)**: 정해진 대사. 초청을 누르면 양측 참석 → 첫 제안에서 한쪽 역제안 → 다시 설득하면 추가 조건 없는 백지평화 합의. API 사용 없음.
- **평화 중재 시험 (실제 AI)**: 설정한 Player2/개인 API와 공통 응답 언어 사용. 양측이 독립적으로 초청 수락/거절, 제안 수락/거절/역제안을 판단. 실제 AI 품질/서비스 연결은 사용자가 확인할 부분이며 이번 자동 검사는 모의 응답이다.
- **결과 기록**: 양측 합의 또는 초청 거절 결과를 앱 userData의 sllm_mediation_records.json에 저장. 왼쪽 ‘저장한 중재 결과’에서 최근 20개 결과와 대화를 열람. 전체 파일은 자동 삭제하지 않음.

## 구현 원칙

- 초청 수락은 회담 참석만 의미한다. 양측의 동일한 백지평화 제안 수락만 합의로 처리한다.
- 추가 영토/배상/보장 조건을 요구하는 답은 역제안으로 분류하도록 AI에 지시한다. 자유 발언으로 실행 가능한 조약 조건을 바꾸지 못한다. 의미 해석은 AI 응답에 의존하며 게임 실행 권한은 없다.
- 전황·참전 이유의 알려진 사실만 프롬프트에 제공한다. 현재 자료는 명시적으로 시험용 가상 자료다.
- 양측 응답을 모두 검증한 뒤 한 번에 반영. 잘못된 ID·중복·누락·알 수 없는 결정은 반영하지 않는다.
- 요청 중 중복 클릭과 회담 교체를 막고, 닫힌 회담의 늦은 응답을 버린다.
- 기록은 원자적 저장, 회담 ID별 중복 저장 방지. 저장 실패/손상 파일을 성공으로 표시하거나 덮어 초기화하지 않는다.
- gameApplied는 항상 false. 실제 게임 명령과 실제 제국 연대기에 접근하지 않는다. 시험 기록에는 시험 출처와 ‘실제 종전 미적용’ 표시를 유지한다.
- 응답은 사용자가 발언할 때만 요청한다. 자동 반복/주기적 AI 호출 없음.
- 기존 정상회담, 모드, DLL을 유지. 앱/모드 연결 규격은 **3 그대로**.

## 검증

- TypeScript 빌드 성공, 단말기/중재 UI 스크립트 구문 확인.
- 전체 검사 PASS 821 / FAIL 0.
- 모의 실행 검사 15개 통과: 개발자 제한, 초청/협상 구분, 역제안, 기록, 잘못된 AI 응답, 중복 요청, 회담 종료 후 늦은 응답 차단, 게임 명령/실제 연대기 의존 없음.
- 실제 AI 서비스·Stellaris 실행과 화면 실사용 검수는 하지 않았다.
