## 1차 적용 완료: Gemini 모델 자동 전환
- 실행 앱과 payload/app에 model-rotation.ts, rotation-service.ts, model-rotation-host.ts 추가.
- aiclient.ts의 기존 HTTP 호출·언어 지시·사용량 기록·잘림 처리를 유지하면서 공식 Gemini 연결에만 선택 기능 연결.
- 기본 비활성. 주 모델을 포함한 최대 8후보. 구조화된 모델별429만 전환; 프로젝트/범위불명429는 대기. 인증·네트워크·400·잘린JSON으로 모델을 순회하지 않는다.
- 자동 전환 콜백은 HTTP 1회만 수행, 기존400 옵션 재시도를 중첩하지 않음. Player2/Vertex/다른 제공자로 넘어가지 않는다.
- AI 설정의 저장된 공식 Gemini 연결 아래 한영/언어팩 설정 컴포넌트. 저장 시 현재 연결 재확인, revision 충돌 검사, 메인 프레임/로컬 설정 화면 검증.
- userData/model-rotation-state.json에 설정과 대기 시각만 원자 저장. API키·본문은 저장하지 않음. 읽기 오류/손상 파일을 빈 설정으로 덮지 않음.
- AiRouter.session의 여러 요청은 동일한 임시 대화ID 사용. ChatOpts.conversationId도 지원. 각 기능의 사용자 턴을 넘는 장기 대화ID 연결은 아직 남음(기능명만으로 묶지 않음).
- 설정 화면의 대기 시각은 조회 시 스냅샷. 실제 사용 모델 실시간 표시와 장기 대화별 상태 UI는 후속 작업.
