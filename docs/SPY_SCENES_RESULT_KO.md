# 첩보 청문회·기자회견 화면 — 2026-10-16

- 청문회: 중앙 은하재판소 재판석, 양쪽 제국 초상화와 진술석, 중앙 현재 증거와 남은 발언 수. 기존 3증거/각 5회 논파·AI 판정 흐름 연결.
- 기자회견: 발표 연단에서 바라보는 1인칭 구도. 전경 마이크와 발표 원고, 정면 7개 가상 기자석·카메라. 기자회견 선택 후 이 화면으로 전환.
- 국내·대외 반응 요약과 발표 참고 메모. 메모는 현재 창에만 유지하며 AI/게임 전송·저장 기능 없음. 기자 질의응답은 이번 범위에 없음.
- 기존 종족 PNG 초상화와 이미지 설정을 사용. 현재 가상 시나리오이므로 플레이어 인간/상대 절지류 및 다양한 가상 기자 종족을 표시. 실제 게임 제국·기자 종족 매핑은 게임 사건 연결 단계에서 처리.
- 한국어/영어 장면 문구 추가. 창 크기가 작으면 스크롤로 모든 입력·결과 접근 가능.
- 실제 Electron에서 두 선택지 전환, 청문회 발언 후 남은 횟수 갱신, 청문회 초상화 2개·기자 초상화 7개 로딩과 가로 넘침 없음, 브라우저 오류 없음 확인. 예시는 실제 UI 캡처이며 게임 자료가 아님.
- 화면 파일만 수정. 첩보 수치/판정/게임 연결 상태 및 모드/DLL은 그대로. 새 설치 EXE 없음.

사용: 앱 재시작 → 설정 → 개발자 모드 → 첩보 대응 시험 → 직접 대면 / 국내 기자회견.
