# 만찬 대화·검증 목록 정리 — 2026-10-16

## 적용

- 실제 게임에서 부착·제거가 확인된 48개는 개발자 검증 화면에서 제외했다. 실제 게임 기능의 수정자 정의는 유지했다. 검증 목록은 미검증 파벌 10개와 관계 3개, 총 13개다.
- 부착·제거 확인 목록은 `src/effect-verified.ts`에 기록했다. 정확한 생산량/기간/기능 자동 적용의 검증 완료를 뜻하지 않는다. 기존 결과 JSON은 보존한다.
- 만찬 화면 오른쪽에 초청 지도자와의 대화 패널 추가. 발언하기 또는 Ctrl+Enter로 전송한다. 실제 AI 호출은 사용자 발언 때만 발생한다.
- 지도자 이름·제국 프로필/윤리관·초대 서신·접대 방식·기존 만찬 대화를 프롬프트에 반영한다. AI가 조약이나 자원 이동을 실행했다고 주장하지 않도록 명시했다.
- `sllm_banquet_chat.json`에 세이브 ID/시간선/방문 ID별 대화를 저장한다. 창 재열기·앱 재시작 뒤 같은 방문에서 이어간다. 기존 기록 파손 시 덮어쓰지 않는다.
- 응답 중 중복 전송 차단, 창 발신자 확인, 세이브/시간선/연결 epoch가 바뀌면 늦은 응답 기록 거부.
- 만찬 시연은 발언할 때 실제 AI를 사용한다. 시연과 실제 방문 기록은 분리한다.

## 통상조약 강제 체결 조사

현재 채팅 적용 경로는 자원·관계·국경·평화·전쟁 등으로 제한되어 있고 통상조약은 연결되지 않았다. 게임 원본 `common/diplomatic_actions/00_actions.txt`에 `action_form_commercial_pact`가 있으나, 이것은 게임의 외교 동작 정의다. 같은 이름을 콘솔 effect로 실행할 수 있다는 뜻이 아니다.

로컬 script_documentation/effects.log와 게임 스크립트에서 `set_commercial_pact`/`create_commercial_pact` 등의 직접 체결 효과는 확인하지 못했다. `has_commercial_pact`로 체결 상태를 읽는 조건은 존재한다. `set_relation_flag`는 임의 관계 플래그를 쓰는 효과로, 실제 조약 생성의 대체 수단으로 취급하지 않는다.

따라서 강제 체결을 작동한다고 주장하거나 가짜 완료 ACK를 추가하지 않았다. 다음 실험은 실제 외교 행동을 실행하는 지원 경로/내부 호출을 확인하고, 대상·현재 상태 검사 → 체결 요청 → has_commercial_pact로 재확인하는 방식이어야 한다. 현재 만찬의 대화상 합의는 게임 조약을 자동 변경하지 않는다.
