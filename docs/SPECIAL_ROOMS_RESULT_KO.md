# 기능별 전용 화면 정리 — 2026-10-16

## 2026-10-16 라디오·서신 디자인 최종 조정

- 성간 라디오는 기존 디자인으로 복원. 작은 오버레이의 폭·스크롤 조정만 유지.
- 지도자 초대 서신 입력란은 테마와 관계없이 맑은 고딕 계열로 표시.
- 앱 및 개발이동 payload에 적용, 예시 이미지 갱신. 새 설치 EXE/ZIP은 생성하지 않음.

## 반영 범위
- 총독실: 풍경 창문, 대표 초상화·의자, 집무 책상과 행성 현황 패널. 행성 목록은 선택 카드.
- 집무실 홀로그램: 아치형 창, 투사기와 광선·투사 링, 별도 현황/통신 기록/입력 패널. 사용자 집무실 배경 선택 시 기본 책상·창·추가 링 숨김 유지.
- 은하 의회: 반원형 의사당의 깊이, 의석과 집계 패널, 안건·발언 영역 정리. 기존 가중 의석 배치 계산 유지.
- 연방 정상회담: 테이블 가장자리·명패·대표 초상화·안건 패널 정리. 기존 회원 수·좌석 계산 유지.
- 연설: 무대 프레임, 연설 목적·진행·국민 반응 패널, 선택 카드와 발언 입력 영역 정리. 사용자별 무대/배경·통치자 초상화 유지.
- 신문: 제호·기사 위계, 종이 질감, 좁은 창에서 기사/한줄 소식 1열 배치. 사용자 언론사 이름/그림/서체/색 및 종이/디스플레이 모드 유지.
- 성간 라디오: 원형 스피커와 수신기 전면, 주파수·방송사 표시, 대본 카드. 작은 오버레이 크기에서도 방송사 선택 및 대본 스크롤 가능.
- 지도자 초대 서신: 외교 문서 형태의 종이 편지 영역과 봉투/문서 느낌의 패널, 예약 영역 정리.

## 유지 범위
- 기본 설정·공통 테마(theme.js)·메인 단말기·런처·알림창은 변경하지 않음.
- 이미 작업한 내정 회의실·평화 중재·만찬·첩보 법정/공식 발표 화면은 변경하지 않음.
- 기능 로직, AI 호출, 게임 효과, 프로토콜, 모드 및 DLL 변경 없음.
- 8개 HTML의 전용 CSS 연결·장식·신문 레이아웃 클래스와 special-rooms.css만 추가/수정.

## 검사
- 숨겨진 실제 Electron 창에서 8개 화면 모두 가상 자료로 렌더링. 브라우저 오류/깨진 이미지/페이지 가로 넘침 없음.
- 정상 크기 및 작은 창 검사: 총독 700×700, 홀로그램 850×640, 의회/정상회담 900×640, 연설 1000×700, 신문 650×700, 라디오 560×210, 초대장 650×650.
- 라디오 방송사 선택, 총독 목록 복귀, 회담 대표 선택, 연설 메모 열기, 사용자 집무실 배경 적용 시 기본 장식 숨김 확인.
- 첫 캡처 도구의 창 종료 처리 문제를 수정하여 전체 검수 재실행 완료. 앱 기능 오류가 아니었음.
- 실제 API/게임은 호출하지 않음. 그림은 실제 UI 캡처이나 데이터는 모두 예시.
- 앱·개발 payload 반영 및 설치기 파일 목록·해시 목록 갱신. 새 EXE/ZIP은 만들지 않음. 기존 전달 ZIP은 이전 스냅샷.
