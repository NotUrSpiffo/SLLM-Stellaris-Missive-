# 건국기념식 전용 그림
Built-in image_gen으로 생성. 국립현충원의 엄숙한 분위기를 모티브로 한 미래 제국 기념비, 화환·불꽃과 경례하는 국민들. 특정 실제 기념물 복제 없음. 중앙 크레딧 여백, 무문양 깃발, 글자 없는 16:9 가로 그림.

저장: 실행 앱 및 payload/app의 ui/assets/ceremony/founding-v1.png.
