# 연방 정상회담 후속 구현 — 2026-10-16

## 이번에 연결한 기능

- 외교 단말기 상단 🤝 버튼으로 실제 연방 회담 열기. 개발자 도구의 실제 연방 읽기도 유지.
- Player2/개인 API 공통 연결과 응답 언어 설정을 사용하는 실제 AI 토론. 현재 앱에서 알고 있는 제국 성향·가치관·정부·관계, 통치자와 연방 정보를 전달. 아직 읽지 않은 프로필을 아는 것으로 취급하지 않음.
- 전체 발언/특정 지도자 발언. 한 요청당 최대 6명씩 묶고, 모든 묶음이 유효해야 입장을 한 번에 반영. 주기적인 AI 자동 호출 없음.
- 첫 입장은 -100~100. 이후 한 차례 입장 변화는 최대 25. 의제가 바뀌면 대화·입장 초기화. 미발언 투표 참여국이 있으면 게임 적용 차단.
- 기존 정해진 대사 시험 유지. 설정 → 개발자 모드 → ‘연방 시험 — 실제 AI 대화 (API 사용)’ 추가. 게임 없이 실제 API로 대화하며 게임 효과는 금지.
- 법 변경·회장 변경·응집력 +10·회원 추방의 명령 생성 및 상태 재조회 경로 구현. **개발자 모드 + 명시적 적용 시험 확인에서만 실행**.
- 적용 직전 회원국·통치자·법·가중치를 재조회해 달라졌으면 중단. 세이브/세션 변경, 중복 클릭과 늦은 AI 응답 차단.
- 요청 전 sllm_summit_apply.json에 기록. 같은 세이브·연방·의제·게임 날짜의 재전송 차단. 손상되거나 기록을 저장할 수 없으면 전송하지 않음.
- 변경 상태를 다시 읽어 확인해야 성공 및 연대기 기록. 불확실하면 자동 재전송하지 않음. 저널에는 적용 의제·요청·확인 상태를 보관하며 전체 회담 대화의 영구 보관은 이번 범위에 없음.
- 연방 조회 모든 줄에 sid/req 식별 추가. 앱/모드 연결 규격 **3**, 네이티브 DLL은 변경하지 않음.
- 확인된 투표 법만 사용. 패권 연합이라는 이유만으로 회장 결정이라고 추정하던 처리 제거. 규칙 미확인 시 앱 회담은 만장일치로 합의하며 이것을 게임의 실제 투표 규칙으로 단정하지 않음.

## 게임에서 남은 검수

1. 최신 앱/모드만 함께 사용하고 HELLO protocol=3 확인. 기존 설치 EXE/창작마당은 자동 갱신되지 않음.
2. 게임을 멈춘 별도 시험 세이브에서 🤝로 회원국·통치자·가중치·법·응집력 조회. FED/FEDMEMBER/FEDLAW/FEDEND의 sid/req 및 스코프 오류 확인.
3. 실제 API로 회원국별 발언과 찬반, 안건 변경 시 입장 초기화, 저장/로드 후 이전 회담 차단 확인.
4. 개발자 모드에서 법 변경·회장 변경·응집력·추방을 각각 별도 시험 세이브로 확인. 게임의 변경 상태와 앱 성공/실패 표시, error.log 대조.
5. **법 해금·DLC·중앙집권 선행 조건·변경 대기시간·실제 연방 투표 시작은 아직 미구현/미검증.** 현재 시험 명령은 직접 효과를 실행하므로 바닐라 UI의 조건을 우회할 수 있음. 따라서 일반 모드의 게임 적용은 잠금. 정식 적용으로 승격하려면 4.5.2 게임 정의와 실행 확인이 필요.
6. 미지원 커스텀 연방 종류/법, 멀티플레이, F-46 메인 메뉴 복귀 감지는 이번에 해결했다고 간주하지 않음.
