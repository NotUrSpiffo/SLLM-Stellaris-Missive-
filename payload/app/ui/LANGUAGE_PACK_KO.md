# SLLM 언어 팩 만들기

언어 팩은 **애드온의 한 종류**입니다. 코드는 들어가지 않고 번역 표(JSON)만 들어갑니다.
켜면 설정 → 인터페이스 언어 선택지에 그 언어가 추가되고, "자동 (게임 언어)"일 때 게임 언어가 맞으면 저절로 고릅니다.

## 1. 뼈대 만들기
설정 → 애드온 → **언어 팩 뼈대 만들기**를 누르면 `문서\SLLM_language_pack_template` 폴더가 생깁니다.

| 파일 | 내용 |
| --- | --- |
| `addon.json` | 애드온 정보 + `"language"` 항목 |
| `strings.json` | 화면 문구 표. 열쇠 = 앱의 한국어 원문, 값 = 지금은 영어 |
| `patterns.json` | 숫자·이름이 들어가는 문구 패턴. `["^편지 (\\d+)통$", "$1 letters"]` 꼴 |

## 2. addon.json 의 "language"
```json
"language": {
  "code": "zh-CN",
  "name": "简体中文",
  "gameLanguage": "l_simp_chinese",
  "system": ["zh"],
  "aiLanguage": "Simplified Chinese",
  "strings": "strings.json",
  "patterns": "patterns.json"
}
```
- `code`: 언어 코드(`zh-CN`, `ja`, `pt-BR` …). `ko`·`en` 은 기본 언어라 쓸 수 없습니다.
- `name`: 선택지에 보일 이름(그 언어로).
- `gameLanguage`: 스텔라리스 언어 이름. 게임을 이 언어로 하면 "자동"이 이 팩을 고릅니다.
- `system`: 게임 언어를 모를 때 맞춰 볼 윈도우 언어 앞부분.
- `aiLanguage`: AI 답장 언어 이름(영어로 쓰는 것이 안전). 사용자가 답장 언어를 따로 정하면 그것이 먼저입니다.
- `strings`·`patterns`: 애드온 안 JSON 파일 경로, 또는 표·배열을 바로 적어도 됩니다.

## 3. 번역하기
- `strings.json` 의 **값만** 바꾸세요. 열쇠(한국어)는 그대로 둡니다.
- 영어 문구를 열쇠로 써도 됩니다. 화면 일부는 한국어 원문 대신 영어 문장을 바로 만들기 때문입니다.
- 번역하지 않은 문구는 지워도 됩니다. 빠진 문구는 **영어**로 보입니다.
- 패턴은 `^`로 시작하고 `$`로 끝나는 정규식만 읽습니다. `$1`, `$2` 자리는 그대로 두세요.

## 4. 설치
- 직접: 설정 → 애드온 → 애드온 폴더 열기 → 폴더째 복사 → 다시 읽기.
- 창작마당: 스텔라리스 모드 안 `sllm/addon/` 에 같은 파일을 넣고 그 모드를 게임에서 켜기.

## 5. 게임 안 문구(선택)
모드의 이벤트 창 글은 스텔라리스 번역 파일입니다. `localisation/english/*_l_english.yml` 을
`localisation/simp_chinese/*_l_simp_chinese.yml` 로 복사해 첫 줄을 `l_simp_chinese:` 로 바꾸고 번역하면 됩니다(같은 모드에 넣어도 됨).

## 한계
- AI 가 쓰는 글(대화·신문·라디오)은 번역 표가 아니라 `aiLanguage` 로 정해집니다.
- 일부 상태 문구·오류 문구는 표에 없을 수 있습니다. 화면에서 영어로 보이는 문구를 그 영어 그대로 열쇠로 넣으면 됩니다.
