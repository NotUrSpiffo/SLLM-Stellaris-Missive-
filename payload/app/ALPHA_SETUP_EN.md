SLLM Missive alpha.8 integrated installer: installs the latest app, its runtime (Electron 31.7.7) and the game DLL; local mod installation is optional. Workshop users should uncheck the local mod option. Otherwise it copies/registers the mod under Documents/Paradox Interactive/Stellaris/mod/sllm_missive_tester. Run the SLLM Missive Tester desktop shortcut (or start_app.bat) after the game finishes loading. Node.js is not required and nothing is downloaded on first launch. No separate unlock patch is required. Existing user history is preserved.
