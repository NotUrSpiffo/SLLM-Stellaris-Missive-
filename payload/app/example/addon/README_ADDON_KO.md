# SLLM 애드온 만들기 (형식 v1)

애드온은 테마 색·그림·모드 해석(가치관·국가 종류·제국 설명·사건)을 한 꾸러미로 묶은 것입니다. 앱은 자료(JSON·그림)만 읽고 코드나 명령은 실행하지 않습니다. 프롬프트 문구 바꾸기는 다음 업데이트에서 지원할 예정입니다.

## 어디에 두나

- **창작마당 모드에 넣기**: 모드 폴더 안에 `sllm/addon/addon.json`과 그림을 넣습니다. 플레이어가 게임 런처에서 그 모드를 켜면 앱이 자동으로 찾습니다(폴더형·ZIP형 모드 모두).
- **직접 넣기**: 앱 설정 → 애드온 → "애드온 폴더 열기"를 누르고, 그 안에 애드온 폴더를 통째로 복사합니다(`addons/내애드온/addon.json`).

모드 하나에는 애드온 하나만 넣습니다. 그림 경로는 `addon.json`이 있는 폴더 기준 상대 경로입니다.

## addon.json

| 키 | 필수 | 내용 |
| --- | --- | --- |
| `version` | 예 | 항상 `1` |
| `id` | 예 | 영문·숫자·`_.-` 1~64자. 애드온마다 달라야 합니다 |
| `name` | 예 | 목록에 보일 이름 |
| `author`, `addonVersion`, `description` | 아니오 | 표시용 |
| `theme` | 아니오 | `{ "name": "...", "colors": { "bg", "panel", "text", "hi", "gold" } }` — `#rrggbb`. 설정의 "테마 적용"으로 사용자 지정 색에 들어갑니다 |
| `images` | 아니오 | `{ "그림 키": "상대 경로" }` — png/jpg/webp, 8MB 이하, 200개까지 |
| `compatibility` | 아니오 | 모드 호환 파일(v1)과 같은 내용: `ethics`, `countryTypes`, `empires`, `events`, `matchModIds` |

### 그림 키

- `ruler:player` — 플레이어 통치자
- `class:<계열>` — 종족 계열 기본 초상화 (예: `class:human`, `class:avian`)
- `class:<계열>#2` … `#8`, `delegate:<계열>#2` … `#8` — 같은 계열의 변형 얼굴. 인물마다 이 중 한 장이 정해져 쓰입니다(통치자·연설 지도자는 변형 없음)
- `delegate:<계열>` — 은하 의회 의원·파벌 대표 얼굴
- `leader:<계열>` — 연설 지도자(계열별)
- `country:<제국 이름>`, `species:<종족 이름>` — 특정 제국·종족
- 장면 배경 슬롯 키(설정의 장면 그림과 같은 이름)

## 우선순위

설정 → 애드온 목록에서 켜고 끄고 ▲▼로 순서를 바꿉니다. 같은 그림·가치관을 여러 애드온이 바꾸면 **위쪽 애드온이 이깁니다**. 사용자가 설정에서 직접 넣은 그림·색은 언제나 애드온보다 앞섭니다. 호환 해석의 적용 순서는 내장 → 모드 안 호환 파일(`sllm/compatibility/*.json`) → 애드온 → 사용자 호환 폴더입니다.

예시는 같은 폴더의 `sllm_addon_example`을 보세요.
